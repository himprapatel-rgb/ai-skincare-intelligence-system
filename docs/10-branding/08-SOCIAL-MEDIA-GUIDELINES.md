## Engagement Guidelines

### Response Times
| Priority | Response Time |
|----------|---------------|
| Customer issues | < 2 hours |
| Questions | < 24 hours |
| Comments | < 48 hours |
| DMs | < 24 hours |

### Tone in Responses
- Friendly and helpful
- Knowledgeable but not condescending
- Empathetic to skin concerns
- Solution-oriented

### Response Templates

**For questions:**
> "Great question! [Answer]. Hope that helps! Let us know if you have other questions."

**For compliments:**
> "Thank you so much! We're so glad [product/app] is working for you!"

**For concerns:**
> "We hear you, and we're sorry you're experiencing this. DM us so we can help sort this out!"

## Crisis Management

### Response Protocol
1. **Acknowledge** - Respond promptly
2. **Apologize** - If appropriate
3. **Take offline** - Move to DM for resolution
4. **Resolve** - Fix the issue
5. **Follow up** - Ensure satisfaction

### Escalation
- Product issues → Support team
- Medical concerns → Recommend professional consultation
- PR issues → Leadership team
