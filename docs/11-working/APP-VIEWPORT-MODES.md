# App Viewport Modes

**Goal:** Mobile looks like a mobile app, tablet looks like a tablet app, desktop looks like a desktop app.

---

## Mobile (≤768px)

- **One-screen experience** – Primary content fits in viewport; minimal scroll
- **Home:** Hero + CTA only; "Learn more" link to About; long sections hidden
- **Bottom nav** – Home, Scan, Dashboard, Shelf, Profile
- **overscroll-behavior: none** – Reduces bounce/overscroll
- **100dvh** – Full viewport height for hero
- **Hamburger** – Full nav with Features/Learn expandable sections

---

## Tablet (769–1024px)

- **Balanced layouts** – 2-column where appropriate
- **CommonStyles** – Tablet page container padding
- **Footer** – Responsive grid

---

## Desktop (1025px+)

- **Full layout** – All sections visible
- **Desktop nav** – Horizontal links + dropdown
- **Wide content** – Max-width containers
