## Lifecycle Rules

- Use active folders for current work, and move completed historical material to [`docs/99-archive/`](../99-archive/).
- Keep legacy root markdown notes indexed in [`docs/99-archive/ROOT-LEGACY-NOTES-INDEX.md`](../99-archive/ROOT-LEGACY-NOTES-INDEX.md).
- Do not delete historical evidence unless it is duplicate or clearly obsolete.
- When introducing a new top-level process doc, update this map and `docs/README.md` in the same change.
- Prefer updating a canonical doc over creating a new one for the same topic.
