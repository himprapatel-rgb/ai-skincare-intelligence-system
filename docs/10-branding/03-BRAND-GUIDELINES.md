# Brand Guidelines

Comprehensive usage guidelines for the AI Skincare Intelligence System brand.

---

## Logo Usage

### Primary Logo
The primary logo combines the AI Skincare Intelligence System wordmark with the SkinIQ icon.

**Minimum Size:**
- Digital: 120px width minimum
- Print: 1 inch width minimum

**Clear Space:**
Maintain clear space equal to the height of the 'S' in 'Skincare' around all sides of the logo.

### Logo Variations

| Variation | Use Case |
|-----------|----------|
| Full Color | Primary use on light backgrounds |
| Reversed | On dark or colored backgrounds |
| Monochrome | Single-color applications |
| Icon Only | App icons, favicons, social avatars |

### Logo Don'ts
- Never stretch or distort the logo
- Never change logo colors outside approved palette
- Never add effects (shadows, gradients, outlines)
- Never place on busy backgrounds without contrast
- Never rotate the logo
- Never rearrange logo elements

## Typography

### Primary Typeface: Inter

**Headings:**
- H1: Inter Bold, 48px/56px
- H2: Inter Semibold, 36px/44px
- H3: Inter Semibold, 24px/32px
- H4: Inter Medium, 20px/28px

**Body Text:**
- Body Large: Inter Regular, 18px/28px
- Body: Inter Regular, 16px/24px
- Body Small: Inter Regular, 14px/20px
- Caption: Inter Regular, 12px/16px

**Special Use:**
- Data/Numbers: Inter Mono, various sizes
- Labels: Inter Medium, 12px/16px, uppercase

### Typography Hierarchy

1. Headlines create impact and draw attention
2. Subheadlines provide context and support
3. Body text delivers detailed information
4. Captions and labels organize and annotate

### Typography Don'ts
- Never use more than 2 type weights on one screen
- Never set body text smaller than 14px
- Never use full justification
- Never use decorative fonts

## Imagery Guidelines

### Photography Style

**Subjects:**
- Real people with diverse skin types, ages, and ethnicities
- Natural, authentic expressions (not overly posed)
- Clean, well-lit environments
- Focus on skin health, not perfection

**Technical Requirements:**
- High resolution (minimum 300 DPI for print, 72 DPI for web)
- Natural lighting preferred
- Minimal retouching - show real skin
- Neutral or brand-color backgrounds

### Illustration Style

**Characteristics:**
- Clean, modern line work
- Brand color palette
- Friendly and approachable
- Educational purpose

**Use Cases:**
- Skin anatomy diagrams
- Process explanations
- Feature illustrations
- Empty states

### Iconography

**Style:**
- 2px stroke weight
- Rounded corners (2px radius)
- Consistent 24x24px grid
- Single color from brand palette

**Categories:**
- Navigation icons
- Feature icons
- Status icons
- Action icons

## UI Components

### Buttons

**Primary Button:**
- Background: SkinIQ Teal
- Text: White, Inter Semibold 16px
- Padding: 12px 24px
- Border Radius: 8px

**Secondary Button:**
- Background: Transparent
- Border: 2px SkinIQ Teal
- Text: SkinIQ Teal
- Same sizing as primary

**States:**
- Hover: Darken 10%
- Active: Darken 20%
- Disabled: 50% opacity

### Cards

**Standard Card:**
- Background: White
- Border: 1px Soft Gray
- Border Radius: 12px
- Shadow: 0 2px 8px rgba(0,0,0,0.08)
- Padding: 24px

### Form Elements

**Input Fields:**
- Height: 48px
- Border: 1px #D1D5DB
- Border Radius: 8px
- Focus: 2px SkinIQ Teal border
- Error: 2px Warm Amber border

## Application Examples

### Mobile App
- Use icon-only logo in navigation
- Maintain 16px minimum padding
- Follow iOS/Android platform guidelines
- Use system fonts for accessibility

### Website
- Full logo in header
- Consistent navigation pattern
- Responsive breakpoints at 640, 768, 1024, 1280px
- Lazy load images for performance

### Social Media

**Profile Images:**
- Use icon-only logo
- Ensure visibility at small sizes
- Maintain brand colors

**Post Templates:**
- Consistent layout system
- Brand color overlays
- Typography hierarchy

### Print Materials

**Business Cards:**
- Full color logo on front
- Contact details on back
- Minimum 300 DPI

**Brochures:**
- Grid-based layout
- Ample white space
- Photography focus
