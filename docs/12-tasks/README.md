# Tasks (Agile Sprint & Product Backlog)

**Single source for sprint backlog and product-backlog-style task lists.**  
See [AGILE-ITERATION-GUIDE.md](../AGILE-ITERATION-GUIDE.md) for how these fit into the iteration cycle.

| File | Agile artifact | Purpose |
|------|----------------|---------|
| [ACTIVE-TASKS.md](ACTIVE-TASKS.md) | **Sprint backlog** | Current iteration – in progress, next, blocked, done this week |
| [BACKLOG.md](BACKLOG.md) | **Product backlog** | Future ideas, not yet planned for a sprint |
| [IMPROVEMENT-BACKLOG.md](IMPROVEMENT-BACKLOG.md) | **Product backlog** | Design, a11y, performance improvements |
| [COMPLETED.md](COMPLETED.md) | — | Reference of completed work |

- **Sprint planning:** Move items from BACKLOG / IMPROVEMENT-BACKLOG (or [03-product/Product-Backlog-V5.md](../03-product/Product-Backlog-V5.md)) into ACTIVE-TASKS.
- **Sprint end:** Move done items to COMPLETED or "Done this week"; carry over or back to backlog as needed.

See [DEVELOPMENT-WORKFLOW](../13-workflow/DEVELOPMENT-WORKFLOW.md) for the mandatory process per change.
