# Agents – 24/7 Automated Work

Four agents run automatically to test, improve, and monitor the app.

---

## Overview

| Agent | Schedule | Purpose |
|-------|----------|---------|
| [E2E Agent](e2e-agent/README.md) | Every 4 hours | Tests GUI (mobile, tablet, desktop). No paid APIs. |
| [Improvement Agent](improvement-agent/README.md) | Daily 06:00 UTC | Lint fixes + Improvement of the Day. |
| [Human Agent](human-agent/README.md) | Daily 10:00 UTC | Login, upload images, navigate like a user. |
| [API Smoke](api-smoke/README.md) | Daily 08:00 UTC | Backend health check. |
