# Working Notes

Living documentation created during active implementation work.

## What goes here

- Integration notes and API wiring details
- Decisions, trade-offs, and rationale
- Environment and configuration changes
- QA notes and quick verification steps
- Iteration logs tracking scope, tests, and risks

## Naming convention

- `YYYY-MM-DD-topic.md` for time-bound work
- `feature-name.md` for ongoing feature threads
